# Cyro

**Cyro** is a lightweight AI built with an Africa-first perspective.

Cyro focuses on **research, knowledge, and useful work** without requiring a heavy AI platform.

## Vision

Build a practical AI that is useful to people across Africa while remaining simple, efficient, and accessible.

## Initial capabilities

- Research and source gathering
- Knowledgebase and persistent project knowledge
- Document and file understanding
- Web research
- Structured answers and summaries
- Lightweight tool use

## Principles

- Africa-first, not Africa-only
- Lightweight by default
- Useful over flashy
- Source-aware research
- Modular model layer
- Build only what we need

## Project

Repository: Cyrosis  
AI: Cyro

The first milestone is a small, working research and knowledge system. More capabilities will be added only when they provide clear value.
