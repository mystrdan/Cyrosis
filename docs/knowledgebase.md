# Knowledgebase

The knowledgebase is Cyro's long-term memory for useful information.

## Initial record

Each knowledge item contains:
- title
- content
- source
- creation time

## Later

- tags
- projects
- document references
- source credibility metadata
- embeddings/semantic retrieval if needed
- relationships between knowledge items

Do not add a vector database until simple retrieval is proven insufficient.
